## Repository Structure

Everything published to the live site lives inside `docs/`.
Source-only files (README, ROADMAP, CHANGELOG) stay at the repository root.

```

KDCN-Digital-Platform/
├── README.md
├── ROADMAP.md
├── CHANGELOG.md
├── .gitignore
│
└── docs/                  ← published site (GitHub Pages)
├── index.html
├── about.html
├── services.html
├── portfolio.html
├── contact.html
├── faq.html
├── privacy.html
├── terms.html
├── careers.html
├── blog.html
├── linktree.html
├── livestream.html
├── resources.html
├── assets/
│
├── client/            ← client portal
├── commerce/          ← commerce layer
├── business/          ← business admin
├── intelligence/      ← AI features
├── blog/              ← blog posts
└── resources/         ← downloadable resources

```
